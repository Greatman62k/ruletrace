   - `cargo tree --offline -p rt-data -e normal` lists rt-compiled, rt-foundation, rt-hash, rt-ir, rt-json, rt-numeric and sha2/digest. It lists no rt-engine, rt-compile, rt-validate, rt-explain, review, cli or AI crate.
   - `cargo tree -p rt-compiled` does not contain `rt-data`, so there is no cycle. rt-engine depends on both.
   - The edge in `allowed-edges.v1` is one line (`rt-data` gains `rt-compiled`), plus the new `forbid-transitive rt-data -> rt-engine rt-compile rt-validate rt-explain rt-review rt-cli rt-ai-*`.
   - Synthetic violation: I temporarily added `rt-validate` to the rt-data dependencies in the scratch worktree. `check-graph` exited 1 with `[edge-not-allowed] edge rt-data -> rt-validate` and `[forbid-transitive] crate rt-data depends on forbidden crate rt-validate transitively`. I reverted the edit.
   - `tests_map.rs`: the assertion set is exactly `{rt-compiled, rt-foundation, rt-json, rt-numeric}`. An engine, compiler, validator or explain dependency still fails it, because the set comparison is exact.
   - Req 24.12 amendment: it permits only reading declarations. It forbids the Rules_Engine, Compiler, Validator, Explainer, review, binary and Auxiliary_Crate, directly or transitively. It is narrow and matches UD-41. The amendment note is also added in the UD list.
2. Move.
   - The five function bodies in `rt-data/src/tabular/compiled.rs` match the deleted app code line for line. The differences are `pub` and doc comments, and `internal` is local.
   - The apps only changed their imports. `evaluate.rs` and `classify.rs` are not in the diff.
   - There is one `rt_engine::evaluate` call per app, in `evaluate.rs` at line 93.
   - The new `tests_compiled.rs` builds hand-written expected `InputSchema`, `TargetKinds` and kind maps from the `slice-basic` compiled fixture. It covers the enum, text, date and collection variants, a mixed-kind target giving `Other`, and a Ranking-typed input that the model refuses to parse. No expectation is computed with the production functions.
3. RN-38 tests.
   - The tests use the real engine (`run_with`) and assert the exact code and message, the rule reference, the exact count, once-only listing in the report, and the matching Indeterminate entry (participant, target and `Missing::Input`).
   - Prize-check has exactly one `ExeMissingValue`. Bracket-check has two Errors, as in F1.
   - Mutants in `rt-engine/src/lib.rs` `unknown_diagnostics` were all killed. See section 7.
