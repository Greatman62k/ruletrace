1. `docs/security/2026-11-20-v1-v4-kill-evidence.md:53` (traceability.md new section, "Design V-1 and V-4" row): the citation "Req 17.8" is wrong for this evidence. Req 17 criterion 8 (requirements.md, Req 17 starts at line 711) is the CLI no-network and byte-identical-output rule. It has no bearing on kills. Req 26 criterion 30 (requirements.md:1044) is the journaled-commit criterion and the harness cites it (`kill_review.rs:357`). Req 37 criterion 17 (session end, termination of children) fits the containment citation. Fix: drop "Req 17.8" or name the intended criterion.
2. `2026-11-20-v1-v4-kill-evidence.md:88-89` (section 5, limit 2): "No kill landed on an empty or partial temporary batch file (V-1 during-states were all a whole temporary file)". The source is the local Linux run in review kill-94f36de finding 4.2. The CI logs print only the counts line and no state classification (grep for `tmp-empty|tmp-partial|tmp-whole` in all four logs finds nothing). So the sentence is unsupported for the three CI runs. Fix: say "in the local Linux runs" or "not observable in the CI logs".
3. `2026-11-20-lt6-browser-evidence.md:37-38`: "no prompt" on the cross-origin POST and "the page texts were as expected" rest on the user's report, not on the raw files. The record attributes the second to the user but not the first. The lab files show only the 403. Minor.
