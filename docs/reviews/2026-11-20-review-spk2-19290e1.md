  reads "no `Authorization` header in any recorder request". It does not say that
  the log must contain the `GET /` block. Step 4 now requires that check, so the
  gap is small. Earlier N4(b) is fixed in step 4 only.
- F2. `crash.rs` `kill_and_measure` (lines 176-197) always polls once before it
  compares against the limit. With `BOUND` = 0 the crash tests a and b therefore
  still pass when the children are already gone at the first poll. Only test d
  (line 339) enforces the bound. Test a and b are not wrong, because a child that
  is absent at about 0 ms does meet a 5 s bound. But the 5 s constant is
  exercised by a single test (see mutant L8).
- F3. The earlier non-blocking findings N1, N2, N3 (design wording) and N5 are
  unchanged. They were not part of this change. N3's `docs/security/` point is
  now stated in the protocol, but the record does not exist yet.

  and line 374, inside test `e_...` which is `#[cfg(unix)]` (line 361). So no
  use exists on Windows. The Windows clippy check below confirms it.
