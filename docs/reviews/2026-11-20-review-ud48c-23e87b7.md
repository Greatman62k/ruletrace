## 4. Non-blocking findings

**N1. Position of the 400 in the check order** (UD-48.md:76-80 against
100-103). Item 1 lists Host, Origin and Sec-Fetch-Site, credentials,
Session_Path and cookie, CSRF. The 400 for dot-segments and encoded `.`, `/`,
`\` is in item 4 but has no place in that order. State whether it comes before
or after the credential check, and test that choice. Either choice leaks
nothing. Also state that the encoded-character test applies to the whole raw
target, so a query containing `%2F` is refused too (check that no form or page
of the Laboratory needs one).

**N2. Section 5 drafts lag section 3.** This is the wording that will be
approved and applied, so fix it before approval.
- Draft 37.6 (167-179) says "a GET request for `/`". Section 3 item 3 requires
  a request target of exactly `/`, so `GET /?x` does not start a session.
  Say "exactly `/`, without a query".
- Draft 37.7 (180-193) has one fixed 403 message. Section 3 has two: item 3
  (no session yet, says to open `/`) and item 4 (adds the instruction to
  restart at once if the user did not start the session). The draft carries
  neither the "restart at once" sentence nor the item 3 text. Residual 2 relies
  on that sentence, so B1's remedy would not reach the applied requirement.
- Draft 37.7 forbids the token only in 401 and 403 responses. Section 3 item 4
  also covers 400.
- C5 (raw byte-prefix match, 32 lowercase hex, 400) and the C6 constant-time
  token comparison have no draft criterion. Draft 37.24 (215-218) covers only
  the cookie.

**N3. Wording.** UD-48.md:27-28 says the token is "never sent to any other
server". True while the user does not visit one at that path, but residual 3
(53-59) shows the user's own page load can address a hostile server. Say "never
sent by the Laboratory to any other server", or "kept from every server except
by the user's own request". Lines 28 and 137 exceed the line width used in the
rest of the file (cosmetic).

**N4. Constant-time comparison of unequal lengths** (item 4). A comparison of
values of different length may exit at once. This leaks only the length of an
attacker-supplied value, which is harmless. Say so in the test, so a mutant that
returns early on equal-prefix bytes is the one that must be killed.

**N5. Evidence on two browsers only.** Row 1 (UD-48.md:37) still says "never
sent to it" (W5 of the earlier review, not required now). Write "not sent
(evidence on Firefox and Google Chrome)".
