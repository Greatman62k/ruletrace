# UD-32 Rank-based qualification

Status: **Confirmed** (option Rank_Reference, applied under the gate rule; reported back to the user for confirmation)

Decision: **Rank_Reference**. One added expression operation, `rank_reference`, reads the Rank_Position of the participant under one declared ranking Target as an Exact_Number operand. A static cycle check returns `RANK_REFERENCE_CYCLE` (Severity Error). A Tie_Group is never cut at the cutoff: every member reads the shared Rank_Position and gets the same Outcome (Req 14.12 a to f).

Affects: Requirements 14.2, 14.5, 14.11 to 14.14, 31, 32.3, 32.4, 33.6. Design §8.9 (D-14), §8.5.

## Basis

- Gate rule (task 1.11): Rank_Reference if the confirmed tournament document states qualification as top places, otherwise Threshold_Only.
- The user confirmed (UD-34) the ICC Men's T20 World Cup 2026 Playing Conditions, clauses 16.10.1 to 16.10.7, and asked to demonstrate group points, ranking, ordered tie-break criteria and top-two qualification. Top-two qualification is a condition on a Rank_Position, so the gate rule selects Rank_Reference.
- Not claimed: bracket generation, seeding, tournament progression (Req 34).
- **The user did not name UD-32 explicitly.** The option was applied under the gate rule and is reported back for confirmation. If the user selects Threshold_Only, the authored script is re-keyed (RN-27) and the Rank_Reference work is removed.
