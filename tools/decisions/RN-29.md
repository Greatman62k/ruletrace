# RN-29 Artifact of `validate` when blocking Diagnostics exist

Status: **Confirmed**

Decision: the user accepted the recommendation, option (a).

Requirements: 17.4, 16.9, 9.2, 33.17. Design: §3.9.1, §8.11.11, §9.4 (RN-29). Consumers: `validate` command (5.4), `compile` command (5.14), mutation M3 (6.9, 11.7).

## Conflict

- Req 17.4 and 16.9 say a failed command creates no file at its output location.
- Req 33.17 needs `compile` to exit 3 after `validate` reported `APPROVAL_UNRESOLVED`.
- Req 9.2 has `compile` return blocking Diagnostics unchanged, which needs a Validation_Result that carries them.

## Options

| Option | Description | Cost |
| --- | --- | --- |
| (a) chosen | `validate` writes the Validation_Result when only blocking Diagnostics prevent success. The exception lists of 17.4 and 16.9 are amended. `compile` refuses such an artifact with exit 3. | Two requirement amendments. The `validate` and `compile` commands must distinguish an artifact with blocking Diagnostics from a usable one. |
| (b) rejected | Change 33.17 so that `compile` exits 2 when no artifact exists. | No requirement exception, but 9.2 cannot be met after `validate`, and mutation M3 would check exit 2 instead of exit 3. |

## Amendments applied to requirements.md

1. Req 16 criterion 9: new exception. When `validate` fails only because of blocking Diagnostics (Error, Ambiguity, Unsupported) in the Rulebook, the CLI writes the Validation_Result carrying them. It is not executable, and `compile` refuses it with exit 3 (17.9).
2. Req 17 criterion 4: the exception list gains the same Validation_Result.
3. Supersession Record: entry "RN-29" added.

## Rules for implementation

- The written Validation_Result carries the blocking Diagnostics, and `compile` re-derives its verdict from them and returns them unchanged, exit 3, with no Compiled_Rulebook file (Req 9.2, 17.9).
- Failures that are not blocking Diagnostics of the Rulebook (for example `RT-VAL-0017`, `RT-VAL-0018`, exit 2) still create no file.

Observable: `Confirmed`, option (a).
