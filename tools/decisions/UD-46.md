# UD-46: LT-6 option A in the requirements

Confirmed by the user on 2026-11-20 ("the wording is ok. proceed"), on the
wording shown after the browser evidence
(`docs/security/2026-11-20-lt6-browser-evidence.md`). It is the draft of UD-45
section 4 with the review findings M2, M4 and M6 of
`docs/reviews/2026-11-20-review-ud45b-9736c58.md` folded in:

- 37.7 names the Origin check as the full check of criterion 4 (M2).
- 37.8 counts only authenticated requests for the 30-minute limit; a refused
  request does not reset it (M6, a new rule confirmed by the user).
- 37.9 states when the CSRF token is first issued (M4).
- 37.18 and 37.25 are included (M4).

The applied text and the Old/New records are in `requirements.md` and in
`traceability.md` section "UD-46 amendments (2026-11-20)". Requirement 37
criterion 23 is unchanged; the run instructions it requires must name the user
name `lab` and the browser prompt when they are written (13.7).

Owed tests in 13.4/13.6 besides the criteria themselves: two Authorization
headers, one valid, give 401 (review finding M1); the Origin check exercised in
the full form of criterion 4, which the prototype did not implement (M2).

LT-6 stays OPEN until an independent reviewer accepts the mitigation in the
threat model.
